# 国际化（i18n）

本插件跟随思源的界面语言自动切换文案，目前支持 **简体中文（默认）** 与 **English**。

## 机制

思源内核会按 `window.siyuan.config.lang` 自动加载 `i18n/<lang>.json` 并挂到 `plugin.i18n`（扁平的 `Record<string, string>`）。插件在 `index.ts` 初始化时把这份字典交给共享单例：

```ts
import { setI18n, t as _t } from "./core/i18n";
// ...
setI18n(this.i18n as unknown as Record<string, string> | undefined);
```

之后任何 UI 代码都用 `t("中文原文")` 取文案，无需关心当前语言。

`src/core/i18n.ts` 暴露两个 API：

- `setI18n(dict)` —— 注入内核给的字典（插件启动时调用一次）。
- `t(key, ...args)` —— 取翻译；支持 `{0}`/`{1}` 占位符替换（如 `t("已删除 {0} 条", n)`）。
  - **缺失兜底**：字典里查不到 key 时，直接返回 key 本身（即中文原文），绝不放空或白屏。这保证新增未翻译的文案在英文界面也至少能看懂。

## 文件结构

```
src/i18n/zh_CN.json   简体中文（恒等映射：key === value）
src/i18n/en_US.json   英文翻译
package/i18n/*.json   构建产物（由 make-package.mjs 从 src 拷贝）
```

- 两个文件 **key 完全一致**，缺一个 key 该语言就会回退到中文。
- 键名约定：**中文原文即 key**。`zh_CN.json` 是恒等映射；`en_US.json` 是翻译值。
- 既有 4 个「命令/菜单」键（`addTask` / `syncNow` / `openPanel` / `insertToday`）是思源 `addCommand` 的 `langKey`，保持 ASCII 扁平键不变，仅在 `langText` 里走 `t()` 本地化。

## 约定

1. **所有面向用户的文案都过 `t()`**，包括 JS 模板字符串里的拼接片段（`${t("未启用")}`）。
2. **运行时动态拼接的片段**（如 `t("「") + name + t("」")`、带 `{0}` 的数目）允许回退中文——这类长尾文案在 `en_US.json` 里未翻时仍会显示中文，属预期行为，不影响使用。
3. 标点键（`。`、`，`、`、`——`、`…`）、纯 URL、数据源地址等无需翻译，原样保留。

## 生成与翻译脚本

源码里的裸中文由 AST 包裹脚本统一包成 `t("...")`（见 `scripts/i18n-wrap-ast.mjs`），随后：

- `scripts/i18n-gen-ast.mjs` —— 扫描 `src/**/*.ts`，抽取所有 `t/_t("...")` 首个字符串参数，生成字典骨架（含 4 个 stock 扁平键）。当前共 **887 个 key**。
- `scripts/i18n-translate.mjs` —— 以 `zh_CN.json` 为唯一来源，逐条产出英文：
  - **精确翻译**：内置 `EXACT` 词表（数组 + Map first-wins 去重）命中整句。
  - **词级翻译**：`TOKENS` 表按长度降序最长匹配，替换句中的已知词。
  - **stock 预翻**：4 个命令键直接给英文。
  - **兜底**：以上都没命中则回退中文原文（优雅降级，不白屏）。
  - 当前英文覆盖率约 **84.7%**（剩余 ~15% 为运行时拼接片段 / 长尾文案，英文界面回退中文）。

> 改源码文案后，重新跑上面两个脚本即可刷新字典；`zh_CN.json` 始终与源码字面量保持一致。

## 新增一种语言

1. 复制 `src/i18n/zh_CN.json` 为 `src/i18n/<lang>.json`（如 `ja_JP.json`）。
2. 把每个 value 翻译成目标语言，key 保持不变。
3. 重新 `npm run build`——`make-package.mjs` 会自动把新文件拷进 `package/i18n/`。
4. 思源切到该语言即生效（内核按 `config.lang` 加载对应文件）。

## 验证

- 单元测试覆盖关键文案的「源码级防漂移」断言（如设置页 `未启用` 提示、冲突报错带账户名、`已取消上传` 文案等），包裹成 `t("...")` 后仍须保留原意。
- 改 i18n 相关代码后务必先 `npm run build` 再 `npm test`：宿主加载的是 `dist/index.js`，顺序错了会拿旧包跑测试（假绿）。
